# GolekFood: Nutrition-Based Food Recommendation App

## Overview

GolekFood is an innovative app that provides food recommendations based on nutrition and nutrition integrated with artificial intelligence (AI) technology. Using accurate food data and nutritional information, the app helps users to make healthier food choices that suit their nutritional needs. GolekFood also provides personalization features, allowing users to set their food preferences and obtain recommendations tailored to their health and lifestyle goals. The app focuses on increasing nutrition awareness and making access to nutrition information easier to support users' healthy lifestyles..

## Tech Stack

- **Python** —  AI model development
- **Flask** — backend API for serving recommendations
- **JavaScript** — frontend interactivity and dynamic content
- **React JS** — frontend framework for building the user interface
- **PHP / Laravel** — legacy backend components for user management and data storage


## Features
- Food recommendation engine based on nutritional content and user preferences
- User profile management with dietary preferences and restrictions
- Integration with external nutrition databases for accurate food information
- Personalized meal planning and recipe suggestions


## Status
> **Archived** — The project is no longer actively maintained or updated. It was developed as a proof of concept for a nutrition-based food recommendation system. While the codebase is available on GitHub, it may not be production-ready or suitable for deployment without further development and testing.

## What I Learned
This project provided insights into the challenges of building a nutrition recommendation system, including data quality issues, the importance of accurate nutritional information, and the complexities of user personalization in health-related applications.

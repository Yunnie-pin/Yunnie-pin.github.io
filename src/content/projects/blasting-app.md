# Kontennova: WhatsApp and Email Blasting App

## Overview

Kontenova is an application for managing blasting scheduled WhatsApp and email messages, built using CodeIgniter 4 and Ajax technology. Its key features include scheduling WhatsApp and email messages, using message templates, customizing scheduling, and providing an intuitive user interface. The app is designed to help users efficiently manage their communication and ensure timely delivery of messages.

![Kontenova](https://i.imgur.com/SEoK9vw_d.webp?maxwidth=100&fidelity=grand)

## Tech Stack
- **PHP / CodeIgniter 4** — backend framework for handling business logic and database interactions
- **MySQL** — relational database for storing message templates, schedules, and user data
- **JavaScript / jQuery** — frontend interactivity for scheduling and managing messages

## Features
- Schedule WhatsApp and email messages for future delivery
- Use message templates for consistent communication
- Customize scheduling with options for one-time or recurring messages
- Intuitive user interface for managing scheduled messages

## Status
> **Internal** — This project is an internal application used within the company and is not publicly available. It is actively maintained and updated to meet the communication needs of the organization. The codebase is proprietary and not accessible outside of the company.

## What I Learned
This project provided insights into building a scheduling system for communications, including handling time-based triggers, managing message templates, and ensuring reliable delivery of messages. It also highlighted the importance of user experience in designing an intuitive interface for managing scheduled tasks.

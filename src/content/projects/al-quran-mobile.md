# Hijrah Journey: Al-Qur'an Mobile App

## Overview

Hijrah Journey is a Flutter-based mobile app designed to help Muslims deepen their faith amidst their busy daily lives. The app provides easy access to the Quran, prayer schedules, hadiths, and various other worship features—all in one platform.

![Logo](https://i.imgur.com/0Uu9Bn8_d.webp?maxwidth=100&fidelity=grand)

## Tech Stack

- **Flutter / Dart** — the primary framework for cross-platform UI (Android & iOS)
- **Firebase** — backend for authentication and data storage
- **Muslim Pro API** — location-based prayer time data
- **Hadith API** — hadith database
- **Al-Qur'an API** — complete Al-Qur'an content

## Features

- Read the full Quran with surah navigation
- Automatic prayer schedule based on location
- Prayer time reminders
- Qibla direction finder
- Asmaul Husna (the 99 Names of Allah)
- Collection of hadiths
- Daily prayers
- Prayer intentions
- Digital tasbih

## Status
> **Archived** — The project is no longer actively maintained or updated. It was developed as a personal project to explore mobile app development with Flutter and to create a useful tool for Muslims. While the app is available on GitHub, it may not be production-ready or suitable for deployment without further development and testing.

# Dews: Fake News Detection App

## Overview

Dews is a hoax news detection website with AI technology. This project was developed as part of the Dews Hackathon, where we aimed to create a tool that can help users identify and filter out fake news from their news feeds. The app uses machine learning algorithms to analyze news articles and determine their credibility based on various features such as source reliability, writing style, and content analysis.

![Dews App](https://i.imgur.com/Fmlte3g_d.webp?maxwidth=760&fidelity=grand)

## Tech Stack

- **Flask** — backend framework for serving the hoax detection API
- **Pandas** — data manipulation and analysis for training the machine learning model
- **Numpy** — numerical computing for machine learning algorithms
- **Laravel** — legacy backend components for user management and data storage
- **React.JS** — frontend framework for building the user interface

## Features

- AI-powered hoax news detection based on machine learning models
- User-friendly interface for submitting news articles and viewing results
- Dashboard for monitoring news credibility and trends
- User authentication and profile management
- Integration with external news APIs for real-time analysis

## Status

> **Archived** — The project is no longer actively maintained or updated. It was developed as a hackathon project and served as a proof of concept for AI-based hoax detection. While the codebase is available on GitHub, it may not be production-ready or suitable for deployment without further development and testing.

## What I Learned

This project provided valuable insights into the challenges of building an AI-powered hoax detection system, including data collection and preprocessing, feature engineering, model training and evaluation, and the importance of user experience in presenting complex AI results in an accessible way. It also highlighted the need for ongoing maintenance and updates to keep such a system effective in the rapidly evolving landscape of online news and misinformation.
